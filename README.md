# bank-managment-oop
Simple bank management system in Python using OOP concepts (accounts, transactions, transfers).
# Features
- Create bank account
- Login with account ID
- Deposit and withdraw money
- Transfer money between accounts
- View transaction history
- Change account name
- Delete account
# How to Run
```bash
python main.py
```
# What I Learned
- Class design and OOP principles
- Managing state between multiple objects
- Building interactive console applications
